# Описание проекта: Свёртка изображений

Данный проект — консольное приложение на C# для обработки изображений. Программа переводит цветное изображение в градации серого и применяет к нему матричный фильтр. В проекте можно сравнить последовательную, параллельную, агентную и GPU-обработку.

## Как работает библиотека (алгоритм)

Основная логика собственной свёртки находится в классе `ConvolutionProcessor`. Ядро фильтра последовательно накладывается на каждый пиксель. Новое значение вычисляется как сумма произведений соседних пикселей на соответствующие коэффициенты ядра.

**Ключевые особенности реализации:**

1. **Ядра разных размеров.** Поддерживаются положительные нечётные размеры: 3 × 3, 5 × 5, 7 × 7 и другие.
2. **Готовые фильтры.** В классе `Kernels` определены размытие (BoxBlur), увеличение резкости (Sharpen) и выделение контуров (Laplacian).
3. **Обработка краёв.** `Extend` повторяет крайний пиксель, а `ZeroPadding` считает значения за границей изображения нулевыми.

Собственная свёртка работает с серым изображением: яркость каждого пикселя хранится в одном байте (0–255). Коэффициенты ядра и промежуточная сумма имеют тип `float`. Цветовые каналы после перевода в серое не сохраняются.

## Последовательная и параллельная версии

- `Convolve` — последовательная свёртка изображения на CPU.
- `ConvolveParallel` — параллельная свёртка по строкам с помощью `Parallel.For`.
- `ConvolveParallelByColumns` — параллельная свёртка по столбцам.

При обработке папки разные файлы также могут обрабатываться одновременно. В вариантах по строкам и столбцам параллелизм по файлам сочетается с параллелизмом внутри изображения. Есть и полностью последовательный вариант: он читает, сворачивает и сохраняет файлы один за другим.

## Агентная модель, GPU и ImageSharp

В CPU-конвейере отдельные агенты читают файлы, выполняют свёртку и сохраняют результаты. Количество читателей, вычислителей и писателей настраивается. В объединённом конвейере вычислителями могут быть как CPU-, так и GPU-агенты.

GPU-свёртка реализована через ILGPU и требует видеокарту с поддержкой NVIDIA CUDA. Для сравнения также доступен библиотечный `BoxBlur` из ImageSharp. В проекте есть несколько вариантов подготовки серого изображения для этого фильтра; они выбираются в меню программы.

## Зависимости и пакеты

Для сборки нужен **.NET SDK 9**. Основные NuGet-пакеты:

- `SixLabors.ImageSharp` — чтение, сохранение и библиотечный фильтр изображений;
- `ILGPU` — вычисления на GPU;
- `BenchmarkDotNet` — отдельные измерения производительности;
- `xUnit` и `coverlet.msbuild` — тесты и покрытие кода.

## Инструкция по сборке и запуску

Склонируйте репозиторий и выполните команды из его корня:

```bash
git clone https://github.com/Vit0GG/ImageConvolution.git
cd ImageConvolution
dotnet restore ImageConvolution.sln
dotnet run --project ImageConvolution/ImageConvolution.csproj -c Release
```

После запуска программа покажет меню. Выберите способ обработки и укажите путь к файлу или папке. Для измерений используйте сборку `Release`. Обработанные файлы сохраняются рядом с входной папкой; другую папку можно задать переменной окружения `IMAGECONV_OUTPUT_ROOT`.

Основные измерения выполняются после прогрева по 25 раз. Время обработки папки включает чтение и сохранение файлов; время свёртки одного изображения в памяти измеряется отдельно. Отчёты записываются в `MeasurementResults/` в рабочем каталоге программы.

## Проверка проекта

```bash
dotnet format ImageConvolution.sln --verify-no-changes
dotnet test ImageConvolution.sln -c Release /p:CollectCoverage=true /p:Threshold=95 /p:ThresholdType=line
```

Порог покрытия строк в CI — 95%. Тесты, требующие CUDA, пропускаются на машине без подходящей видеокарты.
